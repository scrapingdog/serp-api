## 🧪 Quick Start (Node.js)

```js
const axios = require('axios');

const response = await axios.get('https://api.scrapingdog.com/google', {
  params: {
    api_key: 'YOUR_API_KEY',
    query: 'best laptops 2024'
  }
});

console.log(response.data);
```
